# Reward Knowledge

## Retained Insight

The successful family keeps useful risk guardrails while avoiding activity terms that force trading. Reward changes must be evaluated through behavior, exposure, and trade quality, not only NAV.

## Failed Pattern

Reward-only tuning, stronger penalties, imitation bonuses, or simplified rewards repeatedly failed when they increased conservatism globally or created fixed low-position collapse.

## Reusable Method

Separate reward experiments from execution overlays. Use negative-Kelly / expectancy diagnostics when reward changes improve portfolio control but produce weak trade-level quality.

## Next Valid Experiment Type

Only revisit reward if the branch introduces a new reward design or external basis and declares which historical reward failure it avoids.
