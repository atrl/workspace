# Stage1 v4：分钟级配置动作研究

本方案纠正 v3 末尾“每天 09:46 一条配置标签”的错误安排。每日一条标签仍会把盘中路径压成日级动作，不能回答分钟数据是否改善**何时**投入资金。v3 已完成的逐层点时母本、来源身份、SOXX 合同 v2 硬门及所有失败卡仍有效；本方案只替换下一批的接收时钟与动作任务。现役 SIM release 不因研究方案改变。

## 先排除已经失败的机制

先读[八条旧路线与接收器只读归因](../research/stage1_minute_receiver_failure_audit_20261028/conclusion.md)：全天分钟分配器确实用过分钟输入却未过 SOXX，学习分钟权重无稳定信息增量，路径面积完整账户失败，09:46 路径能量/分歧和成交量残差固定版本失败，盘中保护浅树忽略全部分钟输入，独立三选一树不是本路线。不能以改字段名、窗口、模型容量、父本身份或阈值重试这些固定版本。

## 决策和动作单位

- 冻结 f696 的 09:29 五输出、逐年点时 b472 开盘及恢复链作为母本。母本开盘成交后，从每根完整的 Qlib 1 分钟 SOXL/SOXX bar 重新检查**当下**持仓、现金、可用风险容量与分钟特征；同日有数百个潜在决策点，动作时刻由事前冻结规则或模型确定，不固定在 09:46 或 10:32。
- 用源定义的右边界 bar `t`，研究假定信息于 `t+1 分钟`可用，候选订单最早于 `t+2 分钟`后续 bar 开盘成交；不在收市后成交。历史首次真实接收与报价/成交回执仍未认证。先用现有完整分钟 Qlib 来源做时钟、缺失、原价和整股可行动性预检，未知日保持未知。
- 本批研究的是**增加或调整资金配置**，不是 SOXL→SOXX 的暴跌保护。动作只能从当前自身状态和 f696 原始意图出发，在原风险容量、现金与整股约束内选择 `HOLD`、合法现金部署或名义 beta 守恒的 SOXX 中间仓位轮换；具体幅度、每日日内成交上限、费用和恢复日处理必须在标签生成前冻结。若动作空间在风险上限内几乎不可达，就先以 `support_failed` 结束，不偷偷放宽上限。
- 对每个候选分钟，用相同起始持仓和月度 Tiered 费用状态比较“此刻成交”与“不成交／继续等待”的后续资金价值，按原账户下一开盘共同复位；标签在结果和复位成交后才成熟。标签可以每分钟形成，但同日高度相关，不能把 30 万行当 30 万个独立样本。真正策略账户在一次动作后须以**自己的**持仓、现金、风险和费用递推，不能把同状态局部优势相加。

## 先来源与动作，再信息，最后账户

1. 一次只读分钟动作空间预检：核对源 manifest/SHA/NAS 回执及限定读回、父本 1056 日身份、每条 bar 的完整/可用/填单时间、原恢复日、每日有效事件数量、决策前现金与风险容量的日内变化；不得读取未来收益挑时间。记录 2021/2022 各年和半日市，不能只报告分钟总行数。
2. 来源通过后冻结一版合法整股、0bp 额外滑点且扣 Tiered 的分钟动作标签和预算。每个事件的候选与 HOLD 均以当前价格和下次共同复位完整结算；零股数变化、无源、恢复冲突与末端不成熟保持 `unknown`。
3. 信息门以**事件时间**为单位：控制模型拥有同一当下账户状态、已完成分钟普通收益和决策时刻；候选只能增加一项事前定义、与八条旧路径实质不同的分钟机制。训练仅用先前年份已成熟的标签，按交易日分组。必须分别证明分钟数值改变预测、改变**哪一分钟的合法整股成交**，且完整开发日历上费用后价值优于匹配控制与 HOLD；区块不确定性按交易日重采样。全在首个可行动分钟触发、或候选/控制预测逐行相同，直接判 `minute_not_transmitted`，不调树深/阈值救援。
4. 信息通过才准入一笔 2023–2026 复用历史的自身状态完整原生 Qlib 0bp 账户，逐分钟记信号→目标→风险投影→成交→持仓/现金/费用/NAV，完整年度、季度、所有 126 日窗口与盘中风险对齐 SOXX。0bp 全硬门通过后才跑同一冻结版本的 2/5bp。历史通过与独立前向、生产晋升分开。

本计划没有已证明可盈利的分钟特征；预检和信息门是研究准入，不是 SOXX 超额。每批最多 2 个机制、8 个候选、1 个完整资金账户。旧失败卡不重跑；源缺口不由本地缓存或未来历史值补齐。

## 首次只读分钟预检收据

[Qlib 分钟动作空间卡](../research/stage1_intraday_allocation_action_space_20261028/conclusion.md)在 1056 个逐层点时父本日上逐根读取既有分钟来源：1044 个合格日、384660 个潜在决策时点，09:49 至 15:58；10 个恢复日、1 个异常来源日、1 个无下一开盘的末端日排除。929 天的现金与原 beta 上限共同正目标空间随盘中价格变化。此结果只解除“是否又固定成单日 09:46”的来源与时钟疑问；下一步仍须证明实际整股、扣费局部价值、分钟预测增量及完整账户。不可把目标空间冒充成交或超额。

## 首个分钟整股标签固定版及失败

[名义 beta 守恒配置标签](../research/stage1_intraday_beta_neutral_labels_20261028/conclusion.md)实际生成164086条整股含费分钟局部标签，覆盖730日，父本NAV对账通过；但2022仅41个可行动日，低于事前50日门。2022现金中位数70.10%，SOXL权重中位数约0.0020%，SOXL+现金换SOXX的双边订单在多数分钟不可达。关闭此固定动作幅度，不调幅度、阈值或门槛。若继续，同源下一机制须针对**直接可用现金与原有 beta 容量**，而不是假定还有可卖SOXL；先验整股容量和分钟信息，再考虑完整账户。该卡Recorder本地保留，NAS工件API三次HTTP500，暂无归档收据/限定读回。
