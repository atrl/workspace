# 从失败决策到稳定SOXX超额：研究SOP v2

目标和权限以[研究合同v2](three_asset_research_contract.md)为准。此前全部区间诊断、固定实验和关闭条件原字节保存在[历史SOP](archive/research_failure_to_feature_sop_pre_20261020.md)。历史失败路线不能因归档而重开。

## 一份差异报告

从已验证Qlib Recorder输出，统一跟踪：原始预测→配置目标→风险投影→执行/HOLD→持仓及持有时长→费用和净值。完整年度/季度/126日窗口全部保留，未知项明确记录，不依据收益挑选窗口。

报告区分：未学到接收任务的增量、增量未传递到动作、动作改变但完整账户未受益、支持不足或实现缺陷。H5 AUC不能替代日内执行价值，事后现金拖累不证明当时可获利，内生风险状态不是外生市场分组。局部标签的优势不能相加当完整策略收益。

当前主线以冻结Stage1完整链为父方案，先读0bp额外滑点、仍扣IBKR Tiered费用的原生账户。对SOXX的完整年、季度和所有连续126日窗口全量比较，再按决策前可得的状态检查好/差区间；2023、2026的不完整年度单列。每个差区间沿预测、目标、风险投影、动作、持仓、费用和净值追踪，标注现金机会成本、SOXL相对选择与路径反馈各自的位置。分组解释只用于形成假设；不能将事后最差季度、风险状态或窗口直接变成交易规则。0bp通过后才继续合同v2的2/5bp与独立前向门。

从差区间到特征时，先问旧Stage1输入是否已有同义信息，并查已关闭的regime、趋势修复和广度路线。新候选必须说明为何能在决策当时区分“跌势延续/修复”或“广泛下跌/少数权重股拖累”，以及它会进入Stage1的哪一层；先核对NAS来源原件、首次可用时间、缺失日和标签成熟，再冻结匹配对照与信息门。一次信息改善仍须在完整账户及非动机区间复核；复用历史只作开发反馈。

## 候选漏斗

每批最多8个候选、最多2类机制、最多1个完整经济实验。每个候选记录经济假说、接收层、允许字段/数据身份、公式或结构、首次可用时间、标签成熟、固定参数、匹配对照、否定条件、预算及出处。实际研究选择历史继续累计。

1. 先检索失败经验：相同机制、信息和接收器不得只换名字/符号/窗口重试。新证据或实质机制变化须写明。
2. 程序检查字段合法、未来引用、AST重复和复杂度；对已构造信号在相同开发域报告相关性。高相关是冗余线索，不自动残差化或以新表达式自称新信息。
3. 用接收任务匹配的、预先冻结的数值评估获得反馈。数据、公式、代码、窗口身份相同则复用缓存；LLM不凭文字预测IC或签发alpha。
4. 只在训练/开发域选择下一候选。已经事前登记的完整配对经济实验，不能按中间分类/MSE成绩取消或隐藏账户。
5. 结果由独立评审核对SOXX硬门；匹配对照用于验证模块增益。失败版本做一次必要归因，写入失败原因、适用边界及重新开放条件。

## P2的固定接收任务

路径面积P2沿用已批准的6次早期年度拟合、9个旧模型复用、1个2bp物理训练影子账户。复用P1来源，不重新查询行情。先构造同状态、同下一目标复位的合法执行/HOLD标签，再报告成熟、可行动及缺失掩码各自样本数。1055完整前缀/价格/目标交集不是标签数或上限；原有200行门不降低。P2无action分类器或2023+评价账户，新漏斗不得在其中途改变设计。

## 外部研究的采用边界

- [RD-Agent](https://github.com/microsoft/RD-Agent)：研究/实现分工与执行反馈；复用本项目Qlib账户，不另建平台。
- [AlphaAgent](https://arxiv.org/abs/2502.16789)：公式结构去重、假设一致性和复杂度控制。
- [FactorMiner](https://arxiv.org/abs/2602.14670)：记录成功与失败机制、信号相关性，防止重复挖掘。
- [AlphaBench](https://alphabench.cc/)：区分生成、执行和评估，记录每次模型消耗；不能依赖LLM零样本质量评分。
- 量化社区作为线索入口，回溯论文/作者代码/官方数据说明；收益截图、点赞和其他资产结果不作为本项目的验收证据。
