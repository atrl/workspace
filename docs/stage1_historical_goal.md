# Stage1 历史回测优化 Goal

## 完成口径

本 Goal 的对象是精确 f696 配置及 b472 动作、风险、恢复链的改进。仅当一个事前冻结的 SOXL/SOXX/CASH 候选，在训练后的完整原生 Qlib 历史资金账户中，以自身持仓、现金、应收分红、费用和风险状态，通过合同 v2 的 SOXX 0/2/5bp 全部历史财富、回撤、CVaR5、完整年度、126 日窗口及预登记不确定性硬门，才记录 `historical_research_passed` 并完成客户端 Goal。0bp 是零额外滑点，仍扣 IBKR Tiered 费用。部分通过、源资格、训练指标或匹配 Stage1 增益均不能完成 Goal。

2023–2026 历史已反复用于研究；通过也只能称为历史开发回测通过，不能称独立样本成功。合同 v2 的独立前向验证和生产晋升仍是后续独立门槛，但**不属于本 Goal 的完成条件**；不得等待实际新窗口才关闭已通过的历史 Goal，也不得因历史通过自动更换现役策略。

## 每轮唯一主线

每轮从精确 f696 A_0 0bp 账户的一个尚未解决的决策错误出发：预测与原始配置意图、EMA/HOLD 接受目标、自身风险容量、09:46 动作、实际持仓、费用和对 SOXX 净值逐层对齐。保留完整年度、两端不完整年度、16 个季度及全部 819 个重叠 126 日窗口；按决策前已知状态对比好、差区间并披露去重交易日。事后胜负仅用于归因，不生成交易规则。

先核对原 39 项、已关闭卡及相同来源、机制、接收任务。每个候选明确经济错误、决策时钟、来源/首可用时刻、训练标签成熟、接收层、匹配对照、允许的配置/风险结构改动、好区间潜在损害、预算和否定条件。每批沿用 SOP 上限：最多 8 候选、2 类机制、1 个完整经济实验。允许证据支持的跨配置与风险层改动；父本与匹配对照仍为精确 f696+b472，不因结构改动偷换父本。

固定信息门或动作可达性未过即关闭该版本。通过后显式用 `source_targets.frozen_current` 五输出替换原始现金账本的 27baa 提案，并验证 944/944 行父本一致，再跑候选自有状态的完整 0bp 账户。0bp 全门通过才分别运行同一冻结版本的 2/5bp。执行者不能自行签发科学通过；独立评审只核查已冻结的相关门槛。失败版本做一次必要归因后关闭，不改符号、年份、窗口、阈值或名称救援。

无合格候选时，停止同类字段试错，转入一个有界、只读的未解释决策错误归因；形成实质不同且可证伪的机制后才冻结下轮实验。相同阻塞在连续至少三个 Goal 轮次重复、现有数据下无法有意义推进时，按客户端规则报告 `blocked` 和解锁所需的具体证据。预算或会话中断不等于完成。

本复核的结论是：**当前已命名、已核查的现有数据和接收任务下，没有同时具有事前增量信息、合法资金动作与冻结完整账户设计的新候选**。它不证明所有模型不可能胜SOXX，也不重开失败固定版本。后续只有在现有Qlib/NAS里定位到一条实质不同、可验证首次可用时间、训练期增量及双层资金传递的新机制，或用户改变数据/研究边界后，才启动新的拟合和账户。先核查活动索引、关闭理由和来源清单；不要继续按字段或符号逐项试错。

### 后续纠正：具名候选为空不等于研究已无可推进工作

精确f696的[beta守恒合法目标核查](../research/stage1_f696_beta_neutral_rotation_support_20261025/conclusion.md)发现 `SOXL−δ、SOXX+3δ、现金−2δ` 在原797个开盘EXECUTE日中有600日可达，尤其覆盖536个非受限日；先前现金转SOXL动作主要覆盖261个受限日、仅24个非受限日。单独beta守恒版本因受限层仅64日而未过预登记双层支持门，旧静态组成实验仍关闭；但**两种互补的合法动作空间足以支持继续设计联合接收任务**。此前把“无现成账户候选”标为客户端Goal `blocked` 是过早判断，不能当作现有数据的全局不可能性结论。

下一研究单位只允许一个预登记的双层决策机制：同一决策前信息分别回答是否需要现金保护、SOXL相对SOXX是否值得保留，并将输出送入受限层增配与非受限层beta守恒转换。先证明原训练期合法、含Tiered费用、同状态且共同复位的两种局部标签均有跨年支持，再设匹配信息门；任何一层缺支持或信息即停止，不把静态目标容量当作收益。通过后才运行精确f696五输出身份核对和候选自身完整0bp账户。客户端已标 `blocked`，其恢复需用户在Codex执行 `/goal resume`；仓库研究结论与客户端状态分开记录。

**训练母本前置纠正。** [原生Qlib身份审计](../research/stage1_f696_training_label_parent_identity_audit_20261025/conclusion.md)发现，原架构2018–2022物理局部标签账本与f696开发期提案在1056个共同日全部不同，现金权重最大差0.591066。旧信息门失败是其原接收任务的有效结果，但不能证明同字段在精确f696联合接收器上失败。下一步先建立f696逐年向前提案+b472自身风险/动作/恢复的0bp Tiered整股训练参考；其1756行提案已有同日一致性核验。没有这个匹配物理参考前，停止新增单因子H5或旧局部MSE筛选，也不启动完整2023+候选账户。

## 2026-10-28 方法纠正：训练账户的动作模型非逐年向前

[只读模型时钟审计](../research/stage1_methodology_audit_20261028/conclusion.md)确认，上述1056日账户使用的是训练截至2022年的最终b472开盘动作模型；2018–2022年原Recorder另有逐年向前的动作模型，参数均与最终模型不同。此前“精确母本”只指f696五项提案与被指定的最终b472路径身份、现金和Qlib对账，**不代表开发期动作层点时可用**。因此617/304个局部标签与两条信息门负数值保留，但其作用域降为该最终模型回放路径的条件诊断，不能否定真正逐年向前的f696+b472接收器，也不能作为它的最终账户准入门。价格投影未单独认证应收分红、真实历史佣金或完整分钟风险。下一步须先以已保存的逐年开盘模型、对应逐年恢复模型和自身账户状态重建开发期参考；缺少这份逐层点时参考时停止新接收器拟合。客户端Goal状态与此仓库纠正分开。

## 当前研究边界：不再把旧beta硬上限当待办

上述去上限0bp账户已经是一次完整固定消融，且已失败。它主要增加SOXL、降低现金，SOXX平均权重变化很小；原b472动作模型还被置于训练域外并失去恢复资格。下一种研究机制若要在无旧beta硬上限下寻找超额，须重新冻结并训练相应的连续三资产接收任务，明确SOXX中间仓位、持仓期限与风险目标，并与简单同beta/同风险参照及冻结f696+b472父本比较。旧SOXL30%与现金15%也是可研究结构，不能当作用户强制硬门；但只做多、无融资和合同v2的财富、≤30%回撤、CVaR5、年度/滚动窗口及0/2/5bp检验仍有效。没有通过信息门和完整自身状态账户前，不能宣称去上限已找到超额。研究账户未替换现役paper SIM。
