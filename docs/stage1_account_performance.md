# Stage1 模拟账户收益展示口径

`/api/stage1/mobile-summary` schema_version=2。账户金额、账户本金净值变动与
同窗基准比较分别提供；消费端应以 `account_performance` 为账户主指标，不能把
`performance.returns_pct.Stage1` 标成成立以来收益。日报遵循相同规则。

- `account_performance.capital_growth_pct` = 100 × (已对账当前资产 / 实际初始本金 − 1)。
  包含首日变动；仅在初始本金有效且账本 reconciliation.status=matched 时提供。
  `capital_change` 是资产减初始本金，`nav` 是资产除初始本金。
- 该数值未做外部资金流调整。完整资金流证据未接入前，TWR 返回 null/needs_data；
  不能把本金净值变动无条件称作时间加权收益，也不据此计算年化 alpha。
- 为兼容现有消费者，`performance` 保留首个共同 Qlib 结算收盘归一为 1 的序列。
  起止日均为收盘口径，明确排除首日；不将初始本金与首日收盘基准拼接。
- `difference_vs_soxx_pp` 是两条同窗累计收益的算术差，单位为百分点。
  `relative_wealth_vs_soxx_pct` = 100 × (策略同窗财富倍数 / SOXX 财富倍数 − 1)，
  单位为百分比。二者不可混称；均不是费后 alpha。
- 基准为现有 Qlib 结算价格收益，不声称已处理分红和基准交易费用。成立时点
  同刻基准、费用/分红证据尚未齐全，成立以来费后超额返回 null/needs_data。
- `valuation_reconciliation` 同时列出结算日期、快照时点、两者资产及差额。
  不把当前快照覆盖历史收盘，不将差额自动认作手续费，不推断历史扣费时间。
- 保留历史停机和实际持仓路径；已有账户曲线不能证明连续受管理前向绩效。
