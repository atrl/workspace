# Stage1 无旧 beta 上限训练准入：先排除已走过的路

本页用于修复“去上限消融零拟合”被说成“无上限模型已训练”、以及随后提议再训练一个泛化连续模型的两次错位。冻结旧卡保留原结论，当前SIM不变。新候选可以不采用旧beta上限、SOXL30%或现金15%结构；合同v2的只做多、无融资、SOXX费后财富、≤30%回撤、CVaR5、完整年、滚动126日、区块下界和0/2/5bp验收仍有效。

| 已完成路线 | 真实训练与失败作用域 | 新路线不能只重复什么 |
|---|---|---|
| [Stage1 cap3消融](../research/stage1_f696_no_beta_cap_ablation_20261029/conclusion.md) | 精确f696、旧b472，**0新拟合**；相对SOXX财富0.883、可用回撤超过47%；b472见域外cap3且恢复资格机械失效 | 再设cap3，或称它已测试重新训练 |
| [稳定超额连续模型](../research/stable_excess_integration_20261002/conclusion.md) | 3组×3种子已训练，无旧仓位/止损限制；开发期最高相对SOXX财富2.93，但最大回撤83.16%、2022亏70.14%，稳定门失败 | 只换连续softmax或放大SOXL仓位 |
| [基准风险比例模型](../research/benchmark_risk_excess_20261002/conclusion.md) | 4组×3种子已训练，学习SOXL/SOXX组成及风险预算；开发相对SOXX财富0.84–0.95、回撤约46–48%，无信号对照的训练目标甚至未匹配可行SOXX | 只增加一个协方差风险映射 |
| [净超额＋尾部约束模型](../research/constrained_net_excess_20261003/conclusion.md) | 3组×3种子已训练；开发期部分模型费后财富超过SOXX，最差成本正超额年仅2/7且回撤约46%，稳定门失败；其历史成本/父本不同于现役Stage1 | 仅把损失函数改称SOXX相对收益或重复原种子 |
| [基准可达效用模型](../research/benchmark_anchor_utility_20261002/conclusion.md) | 3信息组×3种子训练；价格组相对SOXX财富1.15，但回撤54.60%，训练期保存路径已违反尾部要求 | 只加入基准保底或增加拟合次数 |
| [三选一树](../research/independent_tree_allocation_20261027/conclusion.md) | XGB/LGB已拟合；一步现金起点标签SOXX仅8/1060，硬argmax与合并限制不识别SOXX中间配置 | 用纯赢家标签替代连续权重 |

这些路线使用不同来源、成本和父本；表中数字只用于**机制去重与失败作用域**，不得互相相减、称为现役f696的同条件账户或据此宣告所有连续模型无效。当前研究的真正缺口是：尚无一个在逐层点时f696+b472匹配母本上、用所有合格分钟的决策前信息、以自有持仓和费用后金额及路径风险为目标、在无旧beta硬上限域**实际拟合**的接收器。此缺口不自动构成新机制；只更换母本身份也不够。

下一张研究卡须在结果前给出一项与上表逐条不同的**可证伪信息机制**，源原字节/首可用时间、完整交易日的去重样本、成熟标签、训练/推理同域的连续三资产输出、同状态及同风险简单对照、模型拟合预算和拒绝条件。历史分钟`t+1`可用仍属回溯假定，不能伪装为真实首收回执。训练只用当时成熟的2018–2022点时证据；2023–2026已复用，只能作历史开发诊断。先证明新增信息→连续仓位→整股订单的费用后增量，并保护弱区间之外的好区间；通过才准入一个完整0bp自身状态账户，随后按合同跑2/5bp。若没有可区分的机制，登记`needs_distinct_decision_time_mechanism`，不为了交付“重新训练”而复刻上表。

`src.core.stage1_cap_free_admission`对计划和结果声明做结构性校验：零拟合不能叫重训、二元/纯赢家标签不能叫连续费后价值、训练/推理cap域须一致、旧路线须逐一对照、账户通过须有信息门和0/2/5bp证据。**它不能机器证明新信息真实有效**；独立审查仍须核对具体机制、Qlib Recorder与完整账户。
