# Stage1 分钟级风险容量与资产选择：实施边界

## 2026-10-29 原方案对齐与执行状态

### 期限纠正

一分钟资料提供**决策时点和盘中条件**，并不自动证明该条件有20个交易日的预测寿命。先前把`horizon_sessions=20`从账户回放能力直接写成分钟信号的训练标签期限，是未经验证的期限假设。保留已通过的20会话检查点作为账户路径与风险反馈的技术工具；它不是20日alpha证据，也不要求分钟信号必须预测20日。

下一次经济任务分两层事前冻结：风险方向在各完成分钟可重估，但检验未来至当日收盘、下一开盘及5个交易日的费后动作价值；盘中执行时机只检验同日剩余时段和下一开盘。20会话仅用于已触发动作的完整账户持仓、费用及风险状态追踪。所有候选期限、成熟时刻和交易日重叠排除规则在读取对应结果前固定，逐期限披露并校正同时检验；不得事后挑最有利期限作为新固定版。若分钟输入只改变分钟成交时刻而不改变较长风险判断，不能称它预测中期配置收益。

[首个只读期限核对](../research/stage1_minute_value_horizon_audit_20261029/conclusion.md)复用旧合法现金买SOXX动作，在事前固定的09:48、12:00、15:30三个分钟得到538日996个整股事件。同日收盘、下一开盘、第五会话的平均费后局部增量分别约−0.068、+0.208、+0.593bp；2022三个时点的第五会话均值全部为负。没有新的分钟预测器或完整账户，不能从总体微小正值推断跨日超额，也不能按2020/2022回选期限或年份。旧固定分钟方向/时机模型保持关闭。下一信息试验须先说明新的决策前机制怎样区分同状态好坏事件；否则写`no_admitted_candidate`。

[最早分享里的两道经济问题](https://chatgpt.com/share/6ae0a773-5bf0-83ea-84c1-7cbf698babe5)是：A，现金继续保护还是部署；B，在名义beta不增加时，把部分SOXL和现金换成SOXX是否更好。B的目标变换是`SOXL−δ、SOXX+3δ、现金−2δ`，不是“从现金分别买SOXX或SOXL”。后面的双现金买入分钟预检只覆盖A的两个加仓资产选择；B已在`stage1_intraday_beta_neutral_labels_20261028`按分钟完成固定2.5% SOXL权重的整股含费一步标签，但2022只有41个可行动日，低于事前50日支持门，未进入信息模型和完整账户。另提的多臂减仓方案不是原方案的执行记录。

原方案已完成的环节：精确f696账户的A/B静态目标空间审计；旧开发账户的两类一步局部标签及固定信息门；2026-10-28纠正后的1056日逐层点时f696+b472自身账户；分钟来源与回放器机械门。**旧617/304个A/B标签所在动作模型提前用到了2022年训练参数，不能当成新逐层点时母本上的有效标签。**新母本上尚未运行A/B两类20会话完整自身状态标签或2023–2026新候选账户；B的旧一分钟固定幅度一步标签已因2022支持不足关闭，A的直接现金买SOXX一步标签有支持，但两个固定分钟信息版本失败。新母本只覆盖有匹配分钟源的1056日，不能把2016–2018约700个缺失日期称作已完成。

下一研究单位应先确认B固定版本已因2022持仓支持不足关闭，不以缩小2.5%幅度、降低50日门或换一分钟窗口救援。A虽然有直接现金买SOXX的整股支持，但此前一步方向与时机信息门失败；新接收任务须按上面的期限分层，事前说明相对旧下一开盘共同复位任务的经济差异、匹配控制、分钟信息和否定条件。跨年信息门还须核对预测能否穿过目标和风控成为真实订单。通过后才运行一笔完整0bp账户并按SOXX合同检验。不得把加仓来源空间、事后收益、旧样本内标签或回放一致性当成A/B通过。

## 第二个门：实现可从事件恢复的账户，不先看收益

新增代码放在 `src/backtest/stage1_event_episode.py`，输入明确的 `EpisodeCheckpoint`：事件前调整价持仓、可用现金、已结算NAV/峰值、风险状态及天数、成熟历史收益、月度Tiered股数计数、当日已执行开盘订单、该年冻结的b472开盘／恢复模型身份、f696五输出及Qlib价格身份。2018–2022开发参考使用调整价平面，**没有单独认证应收分红现金流**；checkpoint须将该字段标 `unknown`，不能填成零并称已对账。未来完整原价账户才可用其公司行动账本单独核验。不能只从原账户的次日目标构造候选。

`replay_episode(checkpoint, event, intervention, horizon_sessions=20)` 从每根已完成分钟bar右边界 `t` 生成 `t+1分钟`可用的决策，最早在后续bar开盘 `t+2分钟`按原价整股成交；在随后的20个真实Qlib交易会话逐日调用原动作、风险、恢复链，用该分支**自己的**现金、持仓、费用、峰值与风险状态递推。20会话是账户路径诊断长度，不是分钟信号的预测期限；不能以回放长度替代上文独立冻结的经济标签期限。额外风险容量只在该分支的原有SOXL≤30%、现金≥15%、只做多、无融资结构内研究，未取消SOXX账户风险硬门。

首先用 `intervention=HOLD` 在代表全日／半日、原风险状态变化和原恢复日的日期上做**零干预身份测试**：与封存母本逐股、可用现金、每笔Tiered费用、动作／恢复、日末及第20会话NAV、风险状态和模型时钟对齐；任何一项超过1e-7美元或权重容差即停止。应收分红在开发参考中保持 `unknown`，不能由调整价对账冒充现金流证明。原始2018–2022逐层点时参考的恢复教师不是旧未保存模型的逐字复原，身份只对该新参考及其封存模型负责。需用 Qlib native account／Recorder 留痕，不能以pandas静态叠加代替。

已完成[回放器v1无事件身份门](../research/stage1_event_episode_noop_parity_20261029/conclusion.md)：从起点重放全部1056会话，936日开盘执行、10日恢复、1416笔订单，逐年模型训练截止、目标、整股股数、现金、月度Tiered计数、费用、NAV及风险状态与封存已原生核对的父本**最大差0**。`src/backtest/stage1_event_episode.py` 加入一个严格 `t→t+1决策→t+2成交` 的单事件入口；无事件时不改变父本。聚焦时钟拒绝和合成单笔整股事件检查2项通过。此v1仍每次从起点回放，未检验真实历史事件分支或建立可恢复checkpoint，不可直接用它批量计算标签。下一版先在不读取经济结果的机械测试里导出事件前状态，并核对一笔冻结事件的全历史回放与checkpoint续跑逐项一致；身份未通过不拟合或发布。

## 原第三个门草案：已由期限纠正替代

旧草案曾建议相同名义beta增量最多0.10，分别由现金买SOXX或买 `1/3` 权重的SOXL，并以20会话为标签终点。该动作和20日收益标签**未执行，且不能直接作为下一固定实验**：它混合了分钟执行与中期风险方向，缺少期限依据。上文期限纠正优先；以下旧描述只保留历史决策脉络。

信息输入在事件时只可读已完成bar、f696事前五输出及该分支决策前账户状态。先用原39项、普通价格/波动、现金、风险状态和既有beta缺口作为匹配控制；新增因素须能指出为何它在**相同事前状态**下区分2024Q3式防守价值与2026Q2式风险容量价值，且不重复已关闭的VIX期限结构、路径面积、09:46成交量残差、ret15或价格相对成交量加权代理。先按年份核对两个动作各自的成熟整股支持，2022与其它完整年不能只剩少数样本。训练只用先前年份已成熟标签，按交易日分组并对20会话重叠设purge；信息门看实际资金动作、费用后路径价值、好区间损伤和完整日历区块下界，不用单个IC/AUC签发资格。

信息门通过才准入**一笔**2023–2026已复用历史的自身状态原生Qlib 0bp账户，逐层记录预测→目标→风险投影→整股动作→持仓／费用／NAV；对SOXX报告全部完整／部分年度、16季度、819个126日窗口、回撤、CVaR5和预登记区块下界。0bp全门通过才跑相同冻结版本2/5bp；前向仍单列。此来源和历史反复复用，任何新卡都不是独立验证。

[检查点20会话机械身份门](../research/stage1_event_checkpoint_parity_20261029/conclusion.md)现已通过。2019-12-19事先指定的首个双动作整股可成交分钟为09:48；09:49可决策、09:50填单。无事件续跑对封存父本、SOXX单事件续跑对从起点完整回放，逐日订单、目标、风险状态、现金、费用和NAV差值为0；月度Tiered股数计数一致。这里只确认回放器，未据此评价该事件的收益。下一步回到原A/B价值任务，先在纠正后母本核对B的SOXL＋现金→SOXX等beta整股容量，再事前冻结A/B的20会话费后标签与信息门，按逐年成熟和重叠purge检验。尚无因子拟合或SOXX新候选账户。开发调整价参考的应收分红仍是`unknown`。本地新大Recorder的NAS工件API回执仍有缺口，未核验的对象必须保留。
