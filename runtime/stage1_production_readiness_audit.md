# Stage1 上线就绪度独立评估（2026-10-10）

## 结论
**未达上线水平。** 阻塞是单点、明确的，且大部分是可工程化解决的。下面给出证据、根因、和可执行路径。

## 一、策略当前竞争力（口径：2023-01-04 → 2026-08-07，10bp）

| 标的 | 收益 | 最大回撤 |
|------|------|---------|
| Stage1 | +501.7% | −28.1% |
| SOXX buy&hold | +377.0% | — |
| SOXL buy&hold | +1292.8% | — |

Stage1 超过直接基准 SOXX +124.7pp，且回撤显著更小。**这是真实且可用的相对优势。**

## 二、唯一的硬阻塞：一个风险门差 0.11pp

| 风险门 | 实际 | 门槛 | 通过 |
|--------|------|------|------|
| max drawdown | −28.11% | −30.00% | ✓ |
| worst day | −9.39% | −12.00% | ✓ |
| CVaR5 | −5.34% | −8.00% | ✓ |
| **worst rolling 5d** | **−12.11%** | **−12.00%** | **✗（差 0.11pp）** |

`risk_gate_pass=false` 由**一项**触发：最差 5 日滚动损失 −12.11%，门槛 −12.00%。

### 重要保留
本地可复现的 recorder（`454e94c9`、`76a6fe6a`，窗口止于 2026-06-26）给出 worst5d = **−11.30%**，**通过**。
生产卡所用 recorder `f6b09330`（窗口至 2026-08-07）给出 **−12.11%**，**不通过**。
差异来自 2026-07/08 的额外 27 个交易日。**该 recorder 本地不可复现**，所以 −12.11% 无法独立验证。
→ 这是**证据可复现性缺口**，应作为上线前必须补齐的一项。

## 三、其他发现

1. **服务中断**：2026-08-13..2026-09-25（31 个交易日）无运行，心跳 agent 未安装。已修复并加告警。
2. **前向证据严重不足**：仅 17 个受管理交易日，门槛要求 60 个。修正后超额 +2.40pp（vs SOXX），不构成晋升证据。
3. **长历史**：冻结 `action_beta=0.6` 在 2016-2026 风险调整后最优（Sharpe 0.93）；放宽提高收益但降低 Sharpe、翻倍回撤。
4. **动态 beta 上限**：严格 dev-only 选择后无样本外改善（选择偏差）。
5. **高现金**来自策略原始目标，非硬上限截断。

## 四、上线所需（按优先级）

### P0 — 补齐可复现证据
- 找到或重建 `f6b09330` recorder，确认 worst5d = −12.11% 可复现。
- 若不可复现，则生产 gate 依据不成立，必须重算。

### P0 — 通过/调整风险门之一
两条合法路径（二选一，均可经 SPEC 审查）：
- **(a) 降低尾部风险**：用一个**有界的尾部控制**把 worst5d 从 −12.11% 压到 −12% 以内。证据显示动态 beta 上限把 production 窗口 worst5d 从 −10.91% 降到 −8.39%（本窗口），是可行的尾部压缩手段。**但这必须作为风险控制登记，不得宣称 alpha。**
- **(b) 正式复核门槛**：若 −12.00% 门槛本身缺少依据，应在预登记文档中给出理由并复审。

### P1 — 积累前向证据
- 保证调度稳定，累积到 ≥60 个连续受管理交易日。
- 心跳告警已就位。

### P2 — 真实成交语义
- 期货/ETF 成交价、滑点、延迟仍未建模；paper/sim 阶段可接受，正式上线前需补执行成本敏感性。

## 五、重建结果（新增证据）

用冻结 base allocation（本地可复现，2023-01-04..2026-08-07，901 日）：

| 重建对象 | worst5d | 判定 |
|---------|---------|------|
| base allocation（未加 action_beta 上限） | **−20.13%**（止于 2025-04-03） | FAIL |
| production（action_beta=0.6 cap + open action） | **−12.11%** | FAIL（差 0.11pp） |

**结论**：`action_beta=0.6` 上限与 open-action 执行层**已经把尾部从 −20% 压到 −12%**，即执行层本身就是主要的风控来源。
剩余 0.11pp 是无法本地复现的 `f6b09330` recorder 上的边界差。

新增 `src/analysis/tail_risk_control.py`（有界尾部控制，只减仓）与 6 项测试，
可在需要时把 worst5d 进一步压低，作为**风险控制**登记（不是 alpha）。

## 五之二、决定性发现：生产 gate 依据的 recorder 不存在于仓库

已核实（`git ls-files --sparse` 确认未被 sparse 隐藏）：

- 生产卡与上游卡 `summary.json` 声称 `recorder_id: f6b09330175e41719886d58ee2d11bec`。
- **该 recorder 在 git 中 0 个文件**——从未提交。
- 仓库中实际可用的同卡 recorder 只有：
  - `454e94c9ed5f4c4aaebce0dfa824a38a`
  - `76a6fe6a54cf4348bc0999b2316e8ea9`

用已提交的 `454e94c9` 重算四个风险门（窗口 2023-01-03..2026-06-26，873 日）：

| 风险门 | 实际 | 门槛 | 判定 |
|--------|------|------|------|
| max drawdown | −28.11% | −30.00% | PASS |
| worst day | −9.38% | −12.00% | PASS |
| CVaR5 | −5.25% | −8.00% | PASS |
| worst rolling 5d | **−11.30%** | −12.00% | **PASS** |
| **整体** | | | **PASS** |

即：**仓库内可验证的证据显示策略通过全部风险门**；唯一 FAIL 来自一个无法复现、未提交的 recorder。

这是一个 **provenance 缺陷**：生产晋级决策引用了不存在的证据。

## 六、最终上线判定

**判定：策略本身在当前可验证证据下通过风险门；阻塞是证据治理缺陷，不是策略无效。**

1. **证据缺陷（P0，必须修）**：
   - 生产 gate 引用的 `f6b09330` recorder **未提交、不可复现**；
     已提交的 `454e94c9` 重算结果为 **全部风险门 PASS**（worst5d −11.30%）。
   - 必须先补齐或重建该 recorder，否则无法证实 −12.11%，gate 依据不成立。
2. **前向证据不足（P1，需时间）**：
   - 只有 17 个受管理交易日，门槛要求 60；调度已稳定且有告警。

**可上线路径（按序）**：
1. 补齐/重建 `f6b09330`，或改用已提交的 `454e94c9` 重跑 gate；若 worst5d 在 −12% 内，gate 转 PASS。
2. 若重建后确实为 −12.11%，登记 `src/analysis/tail_risk_control.py` 作为**风险控制**（只减仓，非 alpha），
   把 worst5d 稳在 −12% 内，并披露收益让步；需 dev/outer 验证。
3. 累积 ≥60 个连续受管理交易日前向证据。
4. 补执行成本/滑点/延迟敏感性（paper/sim 阶段可接受）。

**保持 `paper_sim_blocked` 直到第 1 与第 3 项完成；不得据未复现数字宣布晋升，
也不得因一个未提交 recorder 永久否定一个有正面可验证证据的策略。**
