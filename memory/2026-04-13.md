## Futu OpenD integration — RESOLVED

- **Original blocker**: broker adapter and session scripts were complete, but
  OpenD gateway binary appeared undownloadable (all `.zip`/`.dmg` URLs returned
  404; the official download page is geo-blocked for mainland China users).
- **Breakthrough via GitHub research**:
  - Found in Docker repositories that the working URL pattern for macOS is:
    `https://softwaredownload.futunn.com/Futu_OpenD_${VERSION}_Mac.tar.gz`
  - The `.zip` and `.dmg` variants still return 404, but `.tar.gz` serves a
    valid ~380 MB archive containing `FutuOpenD.app`, `FutuOpenD.xml`, and
    `fixrun.sh`.
- **Resolution**:
  1. Created `scripts/install_futu_opend_macos.sh` — one-command automated
     download, extract, and quarantine removal for macOS.
  2. Downloaded and extracted OpenD 10.2.6208 to `~/futu_opend/` on this
     machine, ran `fixrun.sh`, and launched `FutuOpenD.app/Contents/MacOS/FutuOpenD`.
  3. Verified port `127.0.0.1:11111` is open and `check_futu_opend.py` passes.
  4. Updated `production/FUTU_SEMI_AUTO.md`, `skills/futu-api/SKILL.md`, and
     `production/check_futu_opend.py` with the new automated install path.
- **Current status**:
  - OpenD is running locally and reachable.
  - The remaining step to go live (paper) is authenticating with the 富途牛牛
    mobile app QR code scan and ensuring US simulated trading is enabled.
