## Walk-forward harness isolation

- Updated `src/soxl_quant/cli.py` so each walk-forward window can run in its own subprocess worker
- Added:
  - `compact_result()` to strip heavy objects before cross-process persistence
  - hidden worker CLI args for single-window execution
  - `run_worker_profile()` which writes the worker JSON and then exits with `os._exit(0)`
  - `run_walk_forward_isolated()` which reloads worker results in the parent process
- Rationale:
  - qlib under Python `3.14` appears to compute metrics correctly but often fails during interpreter shutdown
  - isolating each window should prevent the parent harness from losing the whole walk-forward pass because one worker dies noisily during cleanup
- Validation:
  - `python3 -m py_compile src/soxl_quant/cli.py soxl_qlib_strategy_v2.py`
  - compact payload check returned `compact_result: OK`
