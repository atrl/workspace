# 精确 f696 Stage1 去 beta 硬上限：0bp 自身账户

用户授权检验移除动作层硬 beta 上限。本固定消融在精确 f696 五输出、b472 开盘动作模型、原始整股价格和公司行动、10万美元起点及 IBKR Tiered 费用上运行 **1 本独立状态原生 Qlib 0bp 账户**，944/944 提案与封存 `source_targets.frozen_current` 一致，现金、股数、费用/NAV 原生对账通过。唯一预先冻结的风险参数干预是把防守、近期亏损和紧急 beta 限值均设为 3.0；SOXL≤30%、现金≥15% 结构仍保留，风险状态时钟仍递推。3.0 高于该三资产只做多目标的 beta，因此开盘目标不再被原 beta 上限投影。原模型看到训练域外的 cap=3.0，恢复资格因 cap=3.0 机械失效；本卡是整条路径的消融，不能孤立解释为某个可交易上限阈值。

去上限相对原 f696 的期末财富比 **1.287**，但相对 SOXX 只有 **0.883**。2024、2025两个完整年度均未跑赢SOXX；819个连续126日窗口仅 **295个（36.02%）**正超额，低于合同70%；预登记63日区块下界 **−0.000715/日**。可用点最大回撤还达 **−47.25%**，超过30%硬门。SOXX财富、回撤、CVaR5、完整年度、滚动窗口和区块六项 0bp 数值门全部失败，决定 `not_promoted_fixed_f696_no_beta_cap_0bp`。不运行本版本2/5bp或宣称历史 Goal 通过。

[逐年持仓归因](failure_attribution.json)显示，去上限将平均 SOXL 权重从原账户的约12.97%–17.20%提高到约16.96%–26.54%，现金相应下降；SOXX平均权重变化较小。新账户风险状态非零 **537日**，原 f696 为 **353日**，两条路径恢复动作均为0。这说明多用现金主要表现为更多 SOXL 风险暴露，并带来更深的自身状态回撤；它不是一个能稳定追上SOXX的简单资金部署办法。2023/2026为部分年度，全部年度/季度与819窗口留在Recorder。此前27baa父本的整层旁路曾出现相对SOXX财富>1，但其944日提案与f696全不一致，不能拿来替代本结果。

本次价格网格仅提供固定成交与可用监控点，未认证完整分钟内回撤；但现有可用点回撤已明显越过30%门，风险失败不依赖补充的分钟资格。2023–2026市场历史已多次复用，本结果只是开发诊断，没有独立前向。NAS研究工件 API 上传失败，本地Recorder保留并有逐对象SHA-256清单；缺少新卡NAS收据和限定恢复证明，不能称已备份。现役SIM release未改变。
