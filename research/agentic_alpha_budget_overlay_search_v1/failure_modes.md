# Failure Modes

- production_signal_budget_overlay: high-return variants beat the production return only by accepting deep drawdowns; drawdown-gated variants retain too little exposure to beat the production baseline.
- tipp_budget_overlay: CPPI/TIPP-style cushion budgeting bounds path drawdown but caps exposure during exactly the high-compounding periods needed to exceed the current production strategy.
- next_action: test a new predictive model family or older intraday history; another budget overlay on the same production score is unlikely to close the full gate.
