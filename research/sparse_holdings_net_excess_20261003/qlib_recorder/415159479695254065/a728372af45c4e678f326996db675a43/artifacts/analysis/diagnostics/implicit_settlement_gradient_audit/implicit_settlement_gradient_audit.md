# 费用结算隐式梯度：拟合前数学与合成审查

本审查通过。仅使用合成持仓、目标、收益和固定0/10/25bp成本；没有市场数据、拟合、参数搜索或旧结果改写。审查实际新版 `src/model/post_fee_settlement.py`，不是替换旧内核的 monkeypatch。

## 数学范围

固定费用率 `0 <= c < 1`，当前持仓h和费用后目标z均为长仓单纯形，r为两项风险资产下标。令

```
t = n*z_r - h_r
n + c*sum(abs(t)) = 1
s = sign(t), exact sign(0) = 0
D = 1 + c*s·z_r
dn/dh_r = c*s/D
dn/dz_r = -c*n*s/D
```

资金方程对n严格递增，斜率下界为 `1-c*||z_r||_1 > 0`；因此正解局部唯一且Lipschitz。非零成交区域内，上式是普通隐式导数。现金坐标的偏导为0；在单纯形上的扰动须通过相应切向量组合这些偏导。

对零成交下标集合Z，固定其他成交符号，枚举Z中的相邻符号 `sigma_i in {-1,+1}`。令 `D_sigma=1+c*sigma·z_r`、`D_0=1+c*s·z_r`，并取

```
mu_sigma = D_sigma / (2**len(Z) * D_0)
```

这些系数严格为正且和为1；相邻梯度 `c/D_sigma*(sigma,-n*sigma)`（顺序h_r、z_r）的加权平均恰等于 `c/D_0*(s,-n*s)`。各相邻区域在自由环境变量中可达：微扰成交t，设置 `n=1-c*sum(abs(t))`、`h_r=n*z_r-t`。所以**符号0规则确实是资金函数在自由环境空间中的一个Clarke广义梯度选择**，也适用于部分成交腿为0的情况；不是对两条不同计算图拼接出来的梯度。

这里使用的广义梯度定义为邻近可微点梯度极限的凸包，见[JMLR论文 Definition 5](https://jmlr.org/papers/volume23/20-899/20-899.pdf)。上述具体资金方程的凸组合证明为本次独立推导，不依赖该论文的优化收敛结论。

**不能扩大这个结论：** 在单纯形边界或固定持仓/政策曲线上，部分环境符号区域可能不可达。选出的向量不一定等于指定可行买入/卖出方向的单侧导数，也不保证任意多步神经网络复合后的向量属于完整目标的Clarke梯度。部分零成交时也不宣称该选择为最小范数。只验证一阶反向传播，不验证二阶导数或优化收敛。

明确反例：`h=(0,.6,.4), z=(0,.4,.6), c=.0025`，SOXL成交为0、SOXX卖出。固定h沿 `dz=(1,0,-1)` 买入SOXL时，符号0反向传播给 `dn=0`，真实可行右导数约 `-0.00250125`。这不反驳环境广义梯度结论，恰说明不能将它称为唯一方向导数。

## 状态与资金链条

费用后目标的下一期归一化状态严格为

```
H(z) = z*(1+r) / sum(z*(1+r))
```

因此它的唯一状态Jacobian不依赖c或h，除非z本身依赖h。实际费用仍由实际成交绝对值计算。由于资金反向传播和绝对值都使用同一实际成交符号，`d[n+fee]=0`，现金扣费恒等式的导数也一致。纯HOLD的复合 `z=h` 给 `dn=0, dfee=0`，状态导数仍随h正确传递；没有切断HOLD状态。

严格只将浮点实际成交恰为0的腿赋符号0。数学上为0但因舍入成为极小非零的成交继续使用实际符号；没有容差交易带或近零吸附。

## 合成结果

49个定向案例覆盖完全零成交、部分零成交（含持仓/目标非零的内部腿）、SOXX边界、纯HOLD、持仓和目标独立扰动、非零成交控制；另有300个固定随机种子的前向案例，以及9个非法数值/持仓/费用输入拒绝案例。非零成交有限差分使用独立单调二分资金解，不复用四符号根。
