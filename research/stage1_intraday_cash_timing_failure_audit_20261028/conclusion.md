# 分钟现金部署模型为什么亏损：只读归因

本卡只读四个封存 Qlib Recorder：逐层点时 f696+b472 原账户、其覆盖的价格框架、165695 条合法现金买 SOXX 分钟标签，以及六次逐年模型的预测、行动和模型对象。重新读取原生 Qlib 一分钟成交点，但**零新拟合、零新候选账户**。所选 341 个行动分支逐一重建整股成交、Tiered 费用与下一开盘共同复位，封存局部标签最大误差为 0。所有数值、来源哈希和 Recorder ID 见 `audit.json`；2021/2022 全日历分别为 252/246 日。

**主要问题是资金投向与买入时机仍不可靠。** 首次合法分钟直接买入，两年都已为负；候选2021年比该机械基线更差，2022年虽少亏，仍为负。候选2021年200次触发中107次实际局部价值为负，2022年141次中69次为负。上述价格损益占候选负局部价值的大部分，费用与复位进一步恶化；优化费用不能把固定信号变为正值。2018–2022市场历史反复复用，这些条件归因不是独立验证。

**分钟信号传递与经济增量要分开。** 对同一个已训练候选模型，仅将新增分钟输入归零，其直接贡献在2021/2022分别改变21/56天的首次行动；候选与单独重拟合的控制模型相差16/33天。候选与控制在首个合法分钟的分数也并非逐行完全相同，尽管新增特征相对当天首次值为零：重拟合会改变截距与共同系数。因此不能把“候选/控制改变16/33天”全部解释为该分钟字段的孤立因果作用。单字段的直接效应存在，但候选总净价值与校正区块门仍失败，不改符号或窗口救援。

**基础价值校准不稳。** 2021年首次合法分钟有213个标签，仅101个事后为正，但候选给162个首次分数预测为正；2022年180个首次标签有83个为正，候选首次预测为正仅39个。2022后来有102天在首次时点之后触发，仍未可靠挑出正净价值。当前任务把“买入后持有到下一开盘”的市场方向与“在当日哪一分钟下单”的执行时机合在一个局部价值目标里；新增成交量加权价格代理改变了时点，却没有补足基础方向判断。这是由已保存预测与标签支持的解释，不是另一个已通过的新目标。

下一步首先修正研究评价边界：现有信息屏只评价事后确有整股成交的分钟，实时运行时必须对所有源可得分钟发出意向，再让执行层处理实际无整股成交或价格变化。以首个可成交点为基线也需要明确其在决策时何时能被确认。当前固定模型已关闭，不在复用年份上重新调符号、15分钟窗口、Ridge强度或触发阈值。若继续研究，须先提出与旧八条路径及本次“买入方向／时机耦合”不同、可点时验证的机制，再冻结标签和信息门；任何局部读数都不等于完整 SOXX 账户超额。

标签和模型两个本地 Recorder 均通过逐对象哈希读取，但 NAS 工件 API 上传失败，缺少收据与限定恢复；本地对象继续保留。本卡复用现有证据，不给这些来源补签 NAS 资格。历史分钟首次真实接收仍未认证。
