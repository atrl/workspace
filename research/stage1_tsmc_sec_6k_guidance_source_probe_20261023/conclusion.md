# TSMC SEC 6-K 季度指引：原件覆盖完成，尚属开发期来源

台积电官网 HTML/PDF 直连 403 后，改用发行人提交至 SEC EDGAR 的原始 6-K。2011、2022、2026 三期原件及完整提交文件均通过精确 CIK、accession、季度指引和 EDGAR 接收头核对；随后读取官方提交索引，在 2011–2026 的 **64 个季度月份**按接收顺序核对，共用 **82 次新 GET** 找到每期首个包含下一季收入区间的原始 6-K。64/64 月有对应原件。原件、响应头、接收记录和索引分批备份 NAS，四个归档远端哈希及指定成员恢复均通过。

来源口径：26 期以 NT$ 十亿表示指引，38 期以 US$ 十亿表示且公告包含 NT$/US$ 假设。64 份文件中的接收头日期均与 SEC filing date 同日。SEC submissions API 的带 `Z` 时间值相对原始接收头有 48 期相差 8 小时、16 期相差 10 小时；本研究**不用该 API 字段作为交易时钟**。SEC [说明](https://www.sec.gov/files/about/webmaster-faq.htm)指出接收时间字段及其对公开可见时间证明的限制，故保守从 filing date 后下一 Qlib 信号日供给，不用公告同日。

统一币种与本季实际收入的数值来源映射见 [新来源卡](../stage1_tsmc_sec_guidance_growth_source_20261023/conclusion.md)。这份原件覆盖和保守时钟可以支持**复用历史的开发期信息检验**，但发行人新闻稿的精确首发时间、SEC 内容首次可见时间及跨期指引可比性尚需进一步确认；零市场收益读取、零模型拟合、零账户，尚未证明 SOXX 超额。
