# Stage1 × ADS 匹配信息检验：固定版本失败

已核对实时版本来源、原 Stage1 3,020 个训练日和 944 个复用诊断日的保守可用性。此卡冻结 39 项原始输入、两项共享来源日龄控制及单一 ADS 候选数值。无拟合 Qlib DatasetH 预检通过：成熟训练 3,014 行、复用诊断 940 行，双方行集一致，ADS 及来源日龄在合格行均无缺失。多重检验门在拟合前修正为 `0.025/25 = 0.001`。

初次预检因默认 Python 3.14 的 OpenMP 重复库终止；切换原 Stage1 同类 Python 3.12 环境后，又发现预检断言误要求冻结队列以外的日期也有 ADS。两次都未拟合；只将断言限定到已冻结的合格行，并保留失败记录。独立设计复核批准精确代码后，完成 **2 次固定 Ridge 拟合、1 次配对区块检验、0 个原生账户**，Qlib Recorder 为 `2859f5a0f084429fb31319c0aa252ef0`，NAS 归档 SHA-256 为 `e017b8d9e0a461ae9b55b120139222ad0eccffa8c472f98bcd5b6893f6a01358`，远端哈希读回通过。

940 条同日配对复用诊断中，基线 MSE `0.002525386`，新增 ADS 后为 `0.002573752`，平均改善 **`−0.000048366`**；新增标准化系数 **`−0.002955`**，与事前正向假说相反。前、后半段改善分别为 `−0.000006506`、`−0.000096343`，固定区块检验下界 `−0.000141078`。四项信息门全部失败。季度差异也不稳定：2024Q3 与 2025Q1 小幅为正，2025Q2 与 2026Q2 显著为负；这些是复用历史上的归因，不可据此挑选季度开关。

决定：`not_promoted_fixed_ADS_information_failed`，关闭此 ADS 水平值 + H5 接收任务的固定版本，不反转符号、不改窗口或年龄阈值补救。来源自身可用，但对原 Stage1 39 项输入未显示稳定增量；没有进入 0bp 账户的依据，更没有稳定 SOXX 超额。后续只在新机制和事前冻结的新接收任务上继续 Goal，且历史复用期仍不具独立性。
