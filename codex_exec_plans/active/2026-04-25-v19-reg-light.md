## Target Improvement Window
wf_2023_2024 (mixed market) while preserving wf_2022 gains

## Accepted Trade-off
wf_2022 may be slightly worse than v19_reg (-21.9%) if wf_2023_2024 improves significantly.

## External Reference
- Srivastava et al. (2014) "Dropout: A Simple Way to Prevent Neural Networks from Overfitting"
- Gal & Ghahramani (2016) "Dropout as a Bayesian Approximation"

## Hypothesis
v19_reg's dropout 0.2 + weight_decay 1e-5 was too aggressive, improving wf_2022 (-21.9%) but hurting wf_2023_2024 (-22.9%). Reducing regularization to dropout 0.1 + weight_decay 1e-6 will preserve most of the wf_2022 improvement while recovering wf_2023_2024 performance.

## Closest Historical Success
v19_reg: wf_2022 Sharpe -0.73 (best in family), return -21.9%

## Closest Historical Failure
v19_reg: wf_2023_2024 Sharpe -0.44, return -22.9% (worse than v19's -0.23/-18.7%)

## Why This Is Not a Duplicate
This is a hyperparameter tuning of the regularization strength, not a new mechanism. It directly addresses the trade-off exposed by v19_reg.

## Implementation Steps
1. Copy v19_reg profile
2. Change dropout from 0.2 to 0.1
3. Change weight_decay from 1e-5 to 1e-6
4. Run fixed-split training
5. If competitive, run walk-forward
6. Compare to both v19 and v19_reg

## Acceptance Criteria
- Fixed-split proxy Sharpe >= 0.80
- Walk-forward wf_2022 return >= -23.0% (near v19_reg's -21.9%)
- Walk-forward wf_2023_2024 return > -18.7% (v19 baseline) OR Sharpe > -0.23
- wf_2020 Sharpe >= 2.0

## Failure Mode
- Lower regularization loses the wf_2022 improvement entirely
- No improvement in wf_2023_2024
- Training instability
